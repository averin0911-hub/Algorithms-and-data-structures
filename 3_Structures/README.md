# Тема 3. Контейнеры (стек, очередь, дек)

## A. Стек с защитой от ошибок

Реализуйте структуру данных **«стек»**. Напишите программу, которая обрабатывает последовательность команд и моделирует работу стека. После выполнения каждой команды программа должна выводить одну строку.

Поддерживаемые команды:

- `push n` — добавить число `n` в стек. Вывести `ok`.
- `pop` — удалить и вывести последний элемент стека.
- `back` — вывести последний элемент, не удаляя его.
- `size` — вывести количество элементов в стеке.
- `clear` — очистить стек и вывести `ok`.
- `exit` — вывести `bye` и завершить программу.

Перед выполнением команд `pop` и `back` необходимо проверить, не пуст ли стек. Если он пуст, вместо числа следует вывести `error`.

### Входные данные

Команды управления стеком, по одной в каждой строке. Последняя команда — `exit`.

### Выходные данные

Протокол работы стека: по одному сообщению на строку для каждой команды.

### Пример

#### Входные данные

```text
size
push 1
size
push 2
size
push 3
size
exit
```

#### Выходные данные

```text
0
ok
1
ok
2
ok
3
bye
```

## B. Правильная скобочная последовательность

Рассмотрим последовательность, состоящую из круглых `()`, квадратных `[]` и фигурных `{}` скобок. Программа должна определить, является ли данная скобочная последовательность правильной.

Пустая последовательность считается правильной. Если последовательность `A` правильная, то последовательности `(A)`, `[A]`, `{A}` также правильны. Если `A` и `B` — правильные последовательности, то последовательность `AB` правильная.

### Входные данные

В единственной строке записана скобочная последовательность, содержащая не более 100000 скобок.

### Выходные данные

Выведите `yes`, если последовательность правильная, иначе `no`.

### Пример

#### Входные данные

```text
()[]
```

#### Выходные данные

```text
yes
```

## C. Постфиксная запись

В постфиксной записи (обратной польской записи) операция записывается **после двух операндов**. Например, сумма чисел `A` и `B` записывается как `A B +`. Запись `B C + D *` обозначает выражение `(B + C) * D`, а `A B C + D * +` — выражение `A + (B + C) * D`.

Вычислите значение выражения, записанного в постфиксной форме.

### Входные данные

В единственной строке записано выражение в постфиксной форме. Оно содержит цифры и операции `+`, `-`, `*`. Числа и операции разделены пробелами. В конце строки может находиться произвольное количество пробелов.

### Выходные данные

Выведите значение выражения.

### Пример

#### Входные данные

```text
8 9 + 1 7 - *
```

#### Выходные данные

```text
-102
```

## E. Дек с защитой от ошибок

Реализуйте структуру данных **«дек»** — двустороннюю очередь, в которую можно добавлять элементы и из которой можно удалять элементы как с начала, так и с конца. Напишите программу, моделирующую работу дека.

Поддерживаемые команды:

- `push_front n` — добавить число `n` в начало дека. Вывести `ok`.
- `push_back n` — добавить число `n` в конец дека. Вывести `ok`.

Гарантируется, что количество элементов дека в любой момент не превосходит 100. Если при выполнении `pop_front`, `pop_back`, `front` или `back` дек пуст, нужно вывести `error`.

## G. Сортировка вагонов

К тупику со стороны пути 1 подъезжает поезд. От него разрешается отцепить один или несколько первых вагонов и завезти их в тупик. Затем можно вывести из тупика один или несколько вагонов на путь 2. В тупике вагоны выводятся в порядке, обратном порядку их помещения туда.

Каждый вагон может не более одного раза заехать с пути 1 в тупик и не более одного раза выехать из тупика на путь 2. Нельзя одновременно перемещать вагоны с пути 1 на путь 2 и обратно.

### Выходные данные

Выведите `YES`, если требуемый порядок можно получить, иначе `NO`.

### Примеры

## H. Гоблины и шаманы

Гоблины любят ходить к шаманам, но из-за большого количества посетителей у шаманов образуются длинные очереди. Чтобы навести порядок, нужно отслеживать положение гоблинов в очереди.

Обычные гоблины становятся **в конец очереди**. Привилегированные гоблины, знающие особый пароль, встают **в середину очереди**. Если длина очереди нечётная, привилегированный гоблин встаёт сразу за центральным элементом.

Обрабатываются три вида запросов:

- `+ i` — обычный гоблин с номером `i` становится в конец очереди.
- `* i` — привилегированный гоблин с номером `i` становится в середину очереди.
- `-` — первый гоблин выходит из очереди и идёт к шаману.

Гарантируется, что при запросе `-` очередь не пуста.

### Входные данные

В первой строке записано число `N` (`1 ≤ N ≤ 10^5`) — количество запросов. Следующие `N` строк содержат запросы в указанном формате. Номера гоблинов удовлетворяют условию `1 ≤ i ≤ N`.

### Выходные данные

Для каждого запроса `-` выведите номер гоблина, который выходит из очереди.

### Пример

#### Входные данные

```text
7
+ 1
+ 2
-
+ 3
+ 4
-
-
```

#### Выходные данные

```text
1
2
3
```

## I. Шарики

В компьютерной игре игрок выставляет в линию шарики разных цветов. Когда образуется непрерывная цепочка из **трёх или более шариков одного цвета**, она удаляется, а оставшиеся шарики сдвигаются друг к другу. После этого могут образоваться новые цепочки, которые также удаляются. Процесс продолжается до тех пор, пока удаление больше невозможно.

Требуется определить, сколько шариков будет уничтожено. Гарантируется, что в начальной последовательности имеется не более одной непрерывной цепочки из трёх или более одноцветных шариков.

### Входные данные

Сначала вводится количество шариков `N` (`N ≤ 1000`), затем `N` целых чисел от 0 до 9 — цвета шариков.

### Выходные данные

Выведите общее количество уничтоженных шариков.

### Пример

#### Входные данные

```text
5 1 3 3 3 2
```

#### Выходные данные

```text
3
```

## J. Конвейер

Материалы из цеха A в цех B перемещаются в одинаковых контейнерах. Контейнеры поступают на конвейер в порядке изготовления, но их нужно отправить в цех B **по возрастанию чисел, обозначающих степень срочности обработки** (меньшее число означает более срочный контейнер).

Для изменения порядка используется накопитель в конце конвейера. Он работает как стек. На каждом шаге разрешено одно из трёх действий:

1. Переместить первый контейнер с ленты непосредственно в цех B.
2. Переместить первый контейнер с ленты в накопитель, поместив его поверх уже находящихся там контейнеров.
3. Переместить верхний контейнер из накопителя в цех B.

Определите, можно ли указанными операциями расположить контейнеры по возрастанию их степени срочности.

### Входные данные

В первой строке записано количество тестов `N`. Далее для каждого теста задано число `K` (`1 ≤ K ≤ 10000`) — количество контейнеров, а затем `K` действительных чисел — степени срочности в порядке поступления из цеха A.

### Выходные данные

Для каждого теста выведите `1`, если нужное упорядочивание возможно, и `0` — в противном случае. Каждый ответ выводится на отдельной строке.

### Пример

#### Входные данные

```text
2
2 2.9 2.1
3 5.6 9.0 2.0
```

#### Выходные данные

```text
1
0
```

## N. Игра в пьяницу

В карточной игре «Пьяница» колода делится поровну между двумя игроками. Каждый игрок одновременно открывает верхнюю карту своей колоды. Игрок, чья карта старше, забирает обе карты и кладёт их вниз своей колоды: сначала свою, затем карту соперника. Проигрывает игрок, у которого закончились карты.

В игре участвуют **10 карт** с номиналами от 0 до 9; все номиналы различны. Обычно более старшая карта побеждает младшую, но есть особое правило: **карта 0 побеждает карту 9**.

Определите победителя и число ходов. Если за `10^6` ходов игра не завершилась, выведите `botva`.

### Входные данные

В первой строке записаны пять чисел — карты первого игрока. Во второй строке записаны пять чисел — карты второго игрока. Карты перечислены сверху вниз, поэтому каждая строка начинается с той карты, которую игрок откроет первой.

### Выходные данные

Выведите `first` или `second`, затем через пробел количество ходов до победы соответствующего игрока. Если игра не завершится за `10^6` ходов, выведите `botva`.

### Пример

#### Входные данные

```text
1 3 5 7 9
2 4 6 8 0
```

#### Выходные данные

```text
second 5
```
